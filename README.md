# Priyanka Yadav · Product Designer

Personal portfolio website — UI/UX and product design work.

## View the site

- **Live:** https://priyankayadav769.github.io/portfolio/
- **Offline:** download `index.html` and open it in any browser.

## What's in this repository

| File | Purpose |
| --- | --- |
| `index.html` | The complete website. All images, videos and icons are embedded in the file, so it works as a single shareable file. |
| `.nojekyll` | Tells GitHub Pages to serve the site as-is. |

Fonts load from Google Fonts and two small scripts (smooth scrolling, physics) load from public CDNs, so an internet connection gives the best experience.
